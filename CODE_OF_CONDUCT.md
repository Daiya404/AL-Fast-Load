# Code of Conduct

## Our standard

Participation in this project should be respectful, constructive, and focused on improving the software. Harassment, personal attacks, discriminatory language, and deliberate disruption are not acceptable.

## Expected behaviour

- Be considerate and respectful.
- Explain technical disagreements with evidence and clarity.
- Accept constructive feedback.
- Focus criticism on code and behaviour, not on people.
- Respect other contributors' time and privacy.

## Project maintainer

Project maintainers are responsible for clarifying and applying these standards in project spaces. Content that violates this code may be edited or removed, and repeated or serious violations may result in exclusion from project spaces.

Concerns can be raised privately with the repository maintainer through GitHub.
