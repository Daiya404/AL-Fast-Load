# Security and privacy reports

Please do not publish credentials, session tokens, cookies, or other sensitive account data in a public issue.

If you believe you have found a security or privacy problem in AniList Fast Load, report it privately to the repository maintainer through GitHub's available private vulnerability reporting feature, if enabled. If that feature is unavailable, contact the maintainer through their GitHub profile and provide only the minimum detail needed to explain the issue.

Please include the affected version, impact, and reproduction details where safe to do so. Do not include real session tokens or other secrets.
